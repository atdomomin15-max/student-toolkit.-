# Student Toolkit

A mobile-friendly starter website with:
- Percentage calculator
- Grade calculator
- 25-minute study timer
- Length unit converter
- Age calculator

## Run it

Keep these three files in the same folder:
- index.html
- style.css
- script.js

Then open `index.html` in a browser.

## Ads

The two "Advertisement" boxes are placeholders. Before adding real ads, choose an ad network you are eligible to use and follow its policies. Replace a placeholder with the network's official ad code only after your site is approved.

## Important

Do not click your own ads, encourage users to click ads, or generate artificial traffic. These can violate advertising-network rules.
